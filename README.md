# Persistent Software

Marketing site for Persistent Software, a software development consulting practice. Showcases the services and background of the practice and drives visitors to get in touch — by email or a scheduled call — rather than through self-serve signup.

**Site: [https://www.persistentsoftware.com/](https://www.persistentsoftware.com/)**

## Features

- Marketing landing page (`/`) covering services and an engineering-process overview, with an animated Terminal element
- About page (`/about`) with founder background, expertise, and services
- Contact via email and a Calendly link — no self-serve signup flow
- Privacy Policy and Terms pages (`/privacy`, `/terms`)
