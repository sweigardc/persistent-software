# Persistent Software

Persistent Software is an independent software engineering practice run by its founder, Chris Sweigard. It builds full-stack web applications and React Native mobile apps, handles payments and integrations, runs AI-assisted code migrations, and offers AI search optimization (SEO, AEO and GEO). It also publishes [tokenlog](https://tokenlog.persistentsoftware.com), a free tool for tracking LLM token usage and cost.

This repository is the marketing site. It showcases the practice's services and background and drives visitors to get in touch by email or a scheduled call, rather than through self-serve signup.

**Site: [https://www.persistentsoftware.com/](https://www.persistentsoftware.com/)**

## Features

- Marketing landing page (`/`) covering services, the engineering process, tokenlog, and what Persistent Software is
- About page (`/about`) with founder background, expertise, services and common questions
- Service pages for mobile apps (`/mobile`), code migrations (`/migrations`) and AI search optimization (`/ai-search`)
- Structured data (Organization, Person, WebSite, SoftwareApplication, FAQPage) and `/llms.txt`
- Contact via email and a Calendly link, with no self-serve signup flow
- Privacy Policy and Terms pages (`/privacy`, `/terms`)
